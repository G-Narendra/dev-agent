Build a complete production-ready portfolio website for Narendra Modi in the portfolio_narendra folder. Follow these steps:

STEP 1 - RESEARCH: Use web_search to find Narendra Modi biography, achievements, government projects, official photo URLs. Use read_url to get detailed info from Wikipedia and government sites. Use free_api with the wikipedia endpoint for accurate data.

STEP 2 - Create portfolio_narendra/package.json using write_file with express, ejs, express-ejs-layouts dependencies.

STEP 3 - Create portfolio_narendra/server.js using write_file. Express server with routes for /, /about, /projects, /contact. Static files from public/. Port 3000. Error handling.

STEP 4 - Create portfolio_narendra/public/css/style.css using write_file. Modern responsive CSS with saffron/white/green Indian flag colors. CSS Grid, Flexbox, animations, mobile-first.

STEP 5 - Create portfolio_narendra/views/layout.ejs using write_file. Common layout with nav bar and footer. Responsive hamburger menu.

STEP 6 - Create portfolio_narendra/views/index.ejs using write_file. Hero section, biography, achievements timeline, featured projects. Use HYPERLINKED images (img src=url from web research) NOT downloaded images.

STEP 7 - Create portfolio_narendra/views/about.ejs using write_file. Detailed biography, early life, political career timeline, milestones. Hyperlinked images.

STEP 8 - Create portfolio_narendra/views/projects.ejs using write_file. Grid of government initiatives: Smart Cities, Digital India, Make in India, Swachh Bharat, Ayushman Bharat. Cards with hyperlinked images, titles, descriptions, stats.

STEP 9 - Create portfolio_narendra/views/contact.ejs using write_file. Contact form, social links, office address. Form validation.

STEP 10 - Run: cd portfolio_narendra && npm install using run_terminal_command.

STEP 11 - Verify server starts: cd portfolio_narendra && node server.js using run_terminal_command.

CRITICAL: Use write_file for EVERY file with COMPLETE production code. Use ONLY hyperlinked images from web. Install packages ONLY inside portfolio_narendra. Do NOT stop until ALL files are created and npm install runs.
